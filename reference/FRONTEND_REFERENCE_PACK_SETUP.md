# Install the frontend reference pack

1. Back up the project before starting.
2. Extract this package into `C:\xampp\htdocs\hunter-system\` so that the `reference\` folder and `CLAUDE_CODE_FRONTEND_REDESIGN_PROMPT.md` appear directly inside the existing project root.
3. Open Claude Code with the working directory set to `C:\xampp\htdocs\hunter-system`.
4. Paste the contents of `CLAUDE_CODE_FRONTEND_REDESIGN_PROMPT.md` into Claude Code.
5. Claude Code must do **Phase 0 only** (read-only audit), then stop and wait. Review the report before telling it `Proceed to Phase 1`.
6. Continue one phase at a time. Do not ask it to implement all phases in one go.
7. Keep the `reference\` folder private and do not place source reference media in the production build.

The package intentionally does not include or replace application source code, SQL files, credentials, or database backups.
